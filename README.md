# Superstore Business Performance & Forecasting Analysis

An end-to-end Excel business analysis project using the Tableau Sample Superstore dataset to evaluate historical sales performance, profitability, budget performance, operational risks, and the 2027 business outlook.

## Project Overview

This project expands the Tableau Sample Superstore dataset beyond traditional sales dashboarding by building a complete business performance and forecasting model in Microsoft Excel.

Using transaction data from 2023–2026, the analysis combines historical performance, profitability, returns, simulated budget targets, forecasting, and scenario modelling to answer three management questions:

1. How has the business performed?
2. Where is performance falling short of expectations?
3. What should management expect in 2027?

The project uses Power Query for data preparation, PivotTables and the Excel Data Model for analysis, budget-versus-actual modelling, and monthly ETS forecasting to produce an executive-level dashboard with actionable recommendations.
